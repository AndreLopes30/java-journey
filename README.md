# Java Journey

Repositório de estudos e exercícios utilizados durante meu aprofundamento em Java.

O conteúdo registra exercícios progressivos sobre fundamentos da linguagem, orientação a objetos, coleções, streams e outros conceitos do ecossistema Java.

> Este repositório é mantido como histórico de aprendizado. Projetos completos estão disponíveis nos repositórios `escola-java` e `escola-java-api`.
